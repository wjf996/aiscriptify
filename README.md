# aiscriptify

AI 小说转剧本工具，面向七牛云 XEngineer 暑期实训营第三批次作品挑战。

## 项目介绍

本项目旨在帮助小说作者将 3 个章节以上的小说文本转换为结构化剧本初稿。工具会辅助提取章节、角色、场景、对白和动作描述，并以 YAML 格式输出，方便作者继续编辑和打磨。

## 目标用户与使用场景

目标用户包括小说作者、编剧初学者和内容创作团队。用户可以输入多章节小说文本，快速获得可编辑的剧本结构，降低从小说改编到剧本初稿的门槛。

## MVP 功能规划

- 支持输入 3 个章节以上的小说文本
- 自动生成结构化剧本 YAML
- 支持作者继续编辑和打磨 YAML 初稿
- 支持复制和下载 YAML
- 编写 YAML Schema 文档并说明设计原因

## 技术栈规划

- 前端：React、Vite、Mantine
- 后端：FastAPI
- AI：真实大模型接口
- 数据格式：YAML
- 文档：Markdown

## 开发流程

本项目按照 PR 分阶段开发，每个 PR 只完成一个明确目标。每个阶段完成后会进行测试，再提交、推送并创建 PR。
